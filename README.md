## About This Project

**fullstack_developer_capstone** is the IBM Full-Stack Software Developer Professional Certificate Capstone project — a comprehensive full-stack web application built with Django (Python) and React, integrating Node.js/MongoDB microservices for dealership and review data, and IBM Watson NLU for sentiment analysis.

**Features:**
- Browse all car dealerships across the United States
- Filter dealerships by state
- View dealer reviews with sentiment badges (positive/neutral/negative)
- Post authenticated reviews with car purchase details
- Admin panel to manage Car Makes and Car Models

## Technology Stack
- **Backend**: Django 3.2 (Python)
- **Frontend**: React.js
- **Microservices**: Node.js + Express + MongoDB (dealerships, reviews)
- **Sentiment Analysis**: IBM Watson NLU
- **Deployment**: IBM Cloud Code Engine / Cognitive Class Labs
- **CI/CD**: GitHub Actions
